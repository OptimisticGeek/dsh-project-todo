## 一、变更摘要

导出此前直接拼接 `task.tags` 的**编码**（`AUTH`、`GALLERY`），而面板早已按标签字典
`docs/ptodo/tags.json` 的 `name` 展示（`账号权限`、`作品展廊`）。本次让导出与面板一致：

- `rowsOf`：标签列按注册表 `code → name` 映射，未命名标签回退编码；Markdown 导出同步生效。
- `reportOf` / 标签 Top：按 `name` 展示与排序；图表类别随表格使用中文名。
- `importRows`：新增标签解析器，按 `code / name / alias` 反查编码。导出的中文名回导后仍
  还原为原编码，不破坏标签体系；未知名称保留原样（可继续新建标签）。
- `importFromFile` 自动读取项目 `tags.json` 参与解析，CLI 与页面导入行为一致。

## 二、验证与证据

- `node --test "test/*.mjs"`：125/125 通过（新增“导出中文名、回导还原编码”用例）。
- 真实数据：fuyao-ai 58 条导出，`任务明细` 标签列显示 `作品展廊 / 模型部署 / 微调训练 /
  执行调度 / 账号权限 / 需求验收…`；`总览` 标签 Top 显示 `账号权限 11 / 监控运维 6 / 需求验收 4…`。
- 回导：把导出文件导入空临时项目，58 条全部导入，标签还原为
  `["GALLERY"]`、`["MODEL-DEPLOY"]`、`["TRAIN"]`、`["INFRA-SCHED"]`、`["tag-0015"]` 等编码。
- 渲染：LibreOffice 5 页（总览 2 + 明细 3），标签图表/明细无英文编码残留（未命名标签除外）。

## 三、风险与待办

- 标签字典里 `name` 仍等于 `code` 的历史标签（如 `REQ`、`INFRA`）会继续显示编码，需在
  `ptodo tag` 里补中文名后重新导出。
- 若标签 `name` 自身包含 `、`/`,` 等分隔符，回导会被拆开；命名时避免使用这些字符。
