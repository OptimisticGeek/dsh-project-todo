# 版本 3.1.1

> **时间**：2026-11-05
> **关联任务**：T-0112（macOS/Linux 跨平台规范化）
> **范围/制品**：`.gitattributes`（新增）、`.github/workflows/ci.yml`（新增）、`package.json`（可移植测试脚本、bin 权限）、`lib/skills.js`（与 locale 无关的排序）、`docs/INSTALL.md`（跨平台章节）
> **证据**：本机 `node --test` 149/149 通过；`git ls-files -s bin/ptodo.mjs` → `100755`；CI 矩阵覆盖 ubuntu/macos/windows × Node 20/22

## 一、变更摘要

**背景**：插件此前只在 Windows 上验证，用户在 macOS 上遇到的安装/运行问题暴露了跨平台盲区。

修复：

- **行尾**：新增 `.gitattributes`，全仓库统一 LF（`*.cmd`/`*.bat`/`*.ps1` 除外）。
  这从根上消除 macOS 上 `env: node\r: No such file or directory` 这类 shebang 问题；
- **可执行位**：`bin/ptodo.mjs` 在 git 索引中改为 `100755`，macOS/Linux 直接执行不再依赖 npm 补权限；
- **测试脚本**：`npm test` 改为 `node --test`（不再依赖带引号的 glob，Node 20/22 与三种 shell 都成立）；
- **CI 矩阵**：新增 GitHub Actions，在 `ubuntu-latest` / `macos-latest` / `windows-latest` × Node 20/22 上跑完整测试，
  平台相关的破坏（symlink、路径大小写、行尾）在 CI 暴露；
- **确定性**：技能目录哈希的排序改为按码点比较（`localeCompare` 依赖系统 collation，macOS 与 Linux 可能不同）；
- **文档**：`docs/INSTALL.md` 新增跨平台章节（链接方式、home 目录、行尾、可执行位、大小写、文件锁）。

## 二、验证与证据

- Windows 本机：`node --test` → **149/149 通过**（测试脚本替换后重跑）。
- `git ls-files -s bin/ptodo.mjs` → `100755 513732b… 0 bin/ptodo.mjs`。
- `git add --renormalize .` 通过，无内容变化（仅行尾/权限正常化）。
- macOS/Linux 的实际运行由新增 CI 矩阵验证；本地无 macOS 环境，未声称已在真机跑过。

## 三、风险与待办

- CI 首次运行需要推送到 GitHub 后触发；若 macOS job 暴露失败，按报错修（最可能：symlink 断言、路径大小写）。
- Trae 的 skills 目录是否被各版本扫描仍取决于 Trae 实现，面板已给出手动导入提示。
- 仍未在真实 macOS 上人工验收 UI；建议发版后让 Mac 用户跑一次 `health` 与「技能」面板。
