## 一、变更摘要

### 1. 问题定位（为什么导出 Excel 用不了）

运行中的 DSH Host 是在插件目录迁移前启动的：`import.meta.url` 仍指向
`E:\java\fuyao-ai\dsh-plugins\dsh-project-todo`，而目录已迁到
`E:\dsh-plugins\dsh-project-todo`。`lib/xlsx.js` 用
`new URL('../tools/xlsx_helper.py', import.meta.url)` 定位 Python helper，
于是实际执行：

```text
C:\Python312\python.exe: can't open file
'E:\java\fuyao-ai\dsh-plugins\dsh-project-todo\tools\xlsx_helper.py':
[Errno 2] No such file or directory
```

HTTP `/export` 又把 `TodoError` 统一成 **200 + JSON**，浏览器把错误 JSON 当
`.xlsx` 保存，Excel 打开即报格式错误。因此 CLI 导出正常、页面导出必坏。

### 2. 修复

- **移除 Python/openpyxl 依赖**：`lib/xlsx-writer.js` 用 `node:zlib` 直接生成
  OOXML + ZIP；`lib/xlsx-reader.js` 纯 JS 解析 XLSX 供 `import-file` 使用。
  导出不再依赖任何插件目录旁的文件，迁移/复制/无 Python 环境都不再受影响。
- **HTTP 语义**：`/export` 失败返回 **500 + JSON**；`client.js` 先看
  `content-type`，JSON 时展示服务端 message，不再下载坏文件。
- **安全**：清掉 XML 非法控制字符；所有文本用 inlineStr 写入，`=SUM(...)`
  这类标题保持文本，不会被当成公式执行。
- 删除 `tools/xlsx_helper.py` 与 `python` 配置项，`package.json` → 2.2.0。

### 3. 导出排版重做

- **`总览`**（A4 横向 2 页）：

  - 7 张 KPI 彩色卡片（总数/已完成/进行中/未开始/阻塞/已取消/完成率）；
  - 状态分布表 + 柱状图（按状态配色）、优先级分布表 + 环形图；
  - 里程碑完成表 + 堆叠柱图（已完成/剩余，图表类别用短编码）；
  - 标签使用 Top10 + 横向条形图；页脚注明数据源。
- **`任务明细`**（A4 横向，逐页重复表头）：
  - 15 列，深蓝表头、冻结首行、自动筛选；
  - 状态整格底色（完成绿/进行蓝/未开始灰/阻塞红/取消紫）、P0/P1 红橙加粗、
    紧急度分级字色；隔行底纹；已完成标题删除线、取消任务灰色斜体；
  - 行高按标题/备注/证据自动估算，日期转本地时间 `YYYY-MM-DD HH:mm`；
  - 页边距/页码页脚/打印区域设置完整，LibreOffice 实测 58 条 = 3 页且无空白页。
