## 一、变更摘要

**1）包名规范化（破坏性）**

- `package.json`：`name` 改为 `dsh-project-todo`，删除 `"private": true`，补 `author` / `keywords`；
- 同步更新 Loader 条目（`cordis.patch.yml`）、客户端模块 id（`client.js`）、Host 头注释（`index.js`）、
  doctor 的兜底包名、技能里的 PATH 降级命令、SPEC / HELP / 技能文档；
- 版本 2.3.0 起 API 已在共享 `/api` 通道，本次不再变更接口。

升级影响：profile 里的依赖名与 `dsh.profile.bundles` 条目必须从 `@local/dsh-project-todo` 改成
`dsh-project-todo`，否则 Host 半边不会加载。本机 desktop profile 已同步并验证可解析。

**2）doctor 收敛**

- **版本文档**：按看板记录回填 13 份历史版本说明（1.0.0 ~ 2.0.3），`version` 检查从 warn 变 ✅；
  回填文件明确标注「按看板记录回填，未重新执行当时的验证」；
- **archive**：从未归档的项目不再报 warn，改为正常状态并提示「首次归档时创建」——
  缺少 `archive.json` 是全新项目的常态，不是故障。

**3）安装文档**

README「安装与接入」重写为公开可用流程：`npm link` / `npm i -g .`、`dsh plugin --profile <name> add <包>`、
`dsh.profile.bundles` 登记、**完全退出 DSH 再启动**、`/api/dsh-project-todo/health` 自检；
去掉机器相关的绝对路径示例。
