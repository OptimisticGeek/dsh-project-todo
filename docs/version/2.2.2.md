## 一、变更摘要

问题：人员下拉把 `optimisticGeek` 与 `OptimisticGeek` 当成两个人（git 历史里有两个作者写法），
选中其中一个时另一个名下的任务不会被过滤出来。

修复（前后端一致）：

- `getPeople` 以 **小写姓名** 为人员键合并条目：
  - 显示名优先级：当前操作人 `person` > 任务里最常见的写法 > git 作者写法；
  - 同一任务内 holder/createdBy/doneBy 的大小写变体只计一次；
  - `source` 取 me > git > task，`active/done/related` 合并累加。
- 客户端：
  - 人员选项按小写去重，默认「与我相关」的匹配也按小写比较；
  - 勾选/取消勾选按小写键操作，避免同一人出现两个勾选项；
  - 指派负责人下拉按小写匹配当前 holder，大小写不同也能正确回显。
- 不改写历史数据、不改 git 作者；显示名沿用当前操作人的写法。
